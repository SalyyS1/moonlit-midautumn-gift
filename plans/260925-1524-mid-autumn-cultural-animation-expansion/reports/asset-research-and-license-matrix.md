# Asset research and license matrix

Date: 2026-09-25

## Recommendation

Build culturally distinctive hero assets in Blender: Cuội, Hằng, rabbits, lân/sư/rồng, bánh giầy tools, drums, lantern motifs, banyan staging and the envelope. Use external libraries only for generic supporting materials or props after checking the exact license and whether a public client-side GLB may redistribute the asset.

| Source | License evidence | Fit | Decision |
|---|---|---|---|
| Poly Haven | https://polyhaven.com/license and https://docs.polyhaven.com/en/faq state CC0 for its assets | Bark, ground, rocks, generic materials | Safe support option; download locally and record hash |
| Kenney | https://kenney.nl/support describes the asset packs as CC0/public domain | Generic filler props | Optional; only if its style fits |
| AmbientCG | https://docs.ambientcg.com/license via the project license links | Bark, soil, cloth and surface maps | Optional support materials |
| Quaternius | https://quaternius.com/license.html permits modified assets in products but has redistribution constraints | Generic blockout/reference | Do not embed without a legal review |
| Sketchfab | https://sketchfab.com/licenses; license is per model | Possible lantern reference/prop | Require exact model page, author, license and attribution; no default download |
| OpenGameArt | https://opengameart.org/node/5571; uploads are mixed | Generic fallback props | Only individually verified CC0 entries |

No downloaded hero model is approved by this research. Search did not produce a trustworthy openly licensed Vietnamese lân/rồng rig. Avoid ripped game/anime models, personal-use STL files, AI assets with unclear provenance, CC-BY-NC, modified CC-BY-ND, hotlinks and “free” pages without explicit terms.

Every adopted external file must record author, exact asset URL, license URL/version, retrieval date, SHA-256, modifications and whether redistribution in the public GLB is allowed in art/THIRD_PARTY_ASSETS.md. CC-BY requires visible credits and bundled notice text. Runtime must remain offline/self-contained.

## Cultural handling

Use Vietnamese references for naming, costume silhouette, lantern/trống/lân motifs and the banyan/moon setting. Treat the rabbit pounding vignette as a playful fictional festival scene rather than a claim that it is a universal Mid-Autumn ritual. Keep the lân/sư beat first; add a dragon procession only after the first dance slice meets visual and performance gates.
