# Third-party asset ledger

Updated: 2026-09-26

The current cinematic GLB contains no downloaded or third-party assets. Cuội,
Hằng, the seated Cuội variant, the two moon rabbits, the lân/sư vignette, the
drum, fire, lanterns, banyan staging, letter props, materials and textures are
authored by this project in `art/blender/`. The public GLB is generated from
those sources; it does not hotlink or load a remote model at runtime.

## Current source and generated assets

| File or asset family | Origin / author | License / redistribution | Retrieval | SHA-256 | Notes |
|---|---|---|---|---|---|
| `art/blender/*.py` | Moonlit Mid-Autumn project | Original project work; no third-party license required | N/A | Source-controlled | Geometry, materials, rigs, actions and export scripts |
| `art/blender/moonlit-world.blend` | Moonlit Mid-Autumn project | Original project work; local authoring source | N/A | Regenerate after source edits | Packed Blender authoring scene |
| `public/assets/models/moonlit-world.glb` | Generated by `art/blender/build-environment.py` | Original project work; redistributable with this project | Generated on export | Run the command below after the final export | Generated output changes when source actions or geometry change |
| `public/assets/posters/scene-00.webp` … `scene-06.webp` | Rendered from the original Blender scene | Original project work; redistributable with this project | Generated on export | Run the command below after the final export | Review/fallback images; Pillow only performs local format conversion |

Generated files are build outputs rather than third-party inputs, so their
hashes must be captured after the final Blender export. This avoids recording a
stale hash while an authored slice is still being rebuilt:

```powershell
Get-FileHash -Algorithm SHA256 public/assets/models/moonlit-world.glb
Get-ChildItem public/assets/posters/*.webp | Get-FileHash -Algorithm SHA256
```

## Adoption rule for future files

No external model or texture may be copied into `public/` without adding a
row here first. The row must include the exact asset page, creator, license
URL/version, retrieval date, SHA-256, modifications and confirmation that a
client-side GLB may redistribute it. Runtime URLs and hotlinks are prohibited.

Poly Haven and Kenney are possible sources for generic support materials only;
their exact license evidence is recorded in the [asset research report](../plans/260925-1524-mid-autumn-cultural-animation-expansion/reports/asset-research-and-license-matrix.md).
Quaternius and Sketchfab remain per-asset review cases. Do not add ripped
game/anime models, personal-use files, AI assets with unclear provenance, or
licenses that prohibit public redistribution.

The ledger is intentionally explicit even for this personal app: it keeps a
future rebuild reproducible and prevents an untracked download from becoming
part of the shipped GLB.
